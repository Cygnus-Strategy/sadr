# Security policy

## Report a vulnerability

Report a vulnerability privately, through GitHub's security advisories:

1. Open the [Security tab](https://github.com/Cygnus-Strategy/sadr/security)
   of this repo.
2. Select **Report a vulnerability**.
3. Describe the problem, the affected version, and the steps to reproduce
   it.

Do not open a public issue, pull request or discussion for a vulnerability.

Cygnus Strategy replies to each report and tells you when a fix is
released. We credit you in the advisory, unless you ask us not to.

## Supported versions

We fix vulnerabilities in the newest release. Adopters pin Sadr by commit
SHA, so update the pin to the release that contains the fix.

## Scope

Reports about these parts are in scope:

- the plugin and its skill, references and scripts
- the reusable GitHub Actions workflow
- the release process and its attestations

A vulnerability in a repo that Sadr upgrades belongs to that repo's
maintainers.
