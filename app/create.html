Create your Sadr App

This page sends Sadr's App manifest to GitHub. GitHub then shows the App it will create, with exactly the permissions in app/manifest.json. You own the App and its private key. Nobody else holds a key to it.

App names are unique across GitHub, and "Sadr" is reserved. Leave this empty to use "Sadr for" and your account name, or pick another free name. Sadr's commits still carry the author name Sadr.

Finish the setup

GitHub created the App and returned a one-time code. It expires in one hour. Run these commands in a terminal where gh is signed in as an owner of the account. They store the App ID and private key as secrets and print neither.

Then upload assets/app/sadr-app-logo.png under "Display information" in the App's settings, and install the App on the account. app/README.md has the details.
